Order Management Help

This page is used to manage customer orders.

How to use it

  • Review the list of orders placed by customers.
  • Use the Fulfill button once an order has been completed.
  • Use Cancel if an order should be removed.
  • Click Details to see the items inside an order.

Important notes

  • When you cancel an order, the order and its items are removed from the system.
  • Fulfilled orders are counted in the sales reports.
  • Pending orders are still visible and can be processed later.

Recommended workflow

  • Check orders daily.
  • Fulfill completed orders quickly.
  • Cancel only if the order is invalid or no longer needed.
