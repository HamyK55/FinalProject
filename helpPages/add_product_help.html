Add Product Help

This page is used to create a new product in the store.

What to fill in

  • Product Name: Enter the product title shown to customers.
  • Description: Add a short description of the item.
  • Category: Choose the correct category for the product.
  • Base Price: Enter the starting price for the product.
  • Stock: Set how many units are available.
  • Active: Leave this checked if the product should appear on the site.

Adding product options

Important: If you want multiple choices to appear in the dropdown on the front-end, use the same Option Name for each option row.

Example:

  • Row 1: Option Name = Size, Option Value = Regular, Price Adjustment = 0.00
  • Row 2: Option Name = Size, Option Value = Large, Price Adjustment = 3.00

This makes the customer see a dropdown called Size with the values Regular and Large.

Images

You can upload one or more product images. The first successfully uploaded image is marked as the primary image.

Tips

  • Use clear option names such as Size, Pack Size, or Color.
  • Use decimal values for price adjustments such as 2.50.
  • Use Sort Order to control the display order of options.
