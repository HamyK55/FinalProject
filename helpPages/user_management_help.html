User Management Help

This page lets admins manage customer and staff accounts.

Actions you can take

  • Disable a user account if they should no longer be able to log in.
  • Reinstate a previously disabled account.
  • Promote a user to admin.
  • Change Role using the dropdown menu.
  • Reset Password to a temporary password.

Important safety note

Admins should not disable or change their own account by mistake. The system prevents that for security.

Temporary password note

When you reset a password, the temporary password is 111111. Make sure to tell the user to change it after logging in.

Tips

  • Use role changes carefully.
  • Only reset passwords when necessary.
  • Keep an eye on disabled accounts if a customer needs their access restored.
